**<a href="https://kejiland.pages.dev">Qingyu'Blog</a>** —— 我的旗舰项目 🔥

- 🪶 **零框架零依赖**：原生 JS / CSS，无构建链，双击 `index.html` 即开即用
- ⚡ **云端一键升级**：Cloudflare Pages + Functions + D1 + KV，全跑在边缘
- 🌍 **五国语言**：中 / 英 / 日 / 韩 / 印地，i18n 零插件实现
- 🔒 **安全内建**：CSP、来源校验、频率限制、PBKDF2 加密文章
- 🎨 **明暗双主题**、全文搜索、留言板、管理后台……全都在一个文件里

```bash
git clone https://github.com/kejiland/qingyu-blog.git && echo "你的博客，从此不需要服务器 🚀"
```
